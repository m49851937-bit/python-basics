# Калькулятор покупок зі знижками

## Призначення програми
Програма призначена для розрахунку вартості покупок
з урахуванням знижок та вартості доставки.

## Основні можливості
- Введення інформації про покупця.
- Введення назви та ціни товару.
- Розрахунок загальної вартості.
- Перевірка умов надання знижки.
- Вибір способу доставки.
- Виведення підсумку замовлення.

## Використані технології
- Python 3.10+
- Git
- GitHub
- Visual Studio Code

## Використані конструкції Python
- Змінні та константи.
- Типи даних int, float, str, bool.
- Функції input() та print().
- Перетворення типів.
- Анотації типів.
- Математичні операції.
- Умови if, elif, else.
- Логічні оператори and, or, not.
- Вкладені умови.
- Умовний вираз.
- Конструкція match-case.
- Коментарі та f-рядки.

## Інструкція із запуску
1. Завантажити репозиторій.
2. Відкрити папку з програмою.
3. Запустити файл main.py командою:

python main.py
